
# 🚀 CareerCo-Pilot

---

## 📌 Overview

**CareerCo-Pilot** is an AI-driven job search automation system that transforms **WhatsApp into a personal career assistant**.

Instead of manually browsing LinkedIn, users simply send a message on WhatsApp. The system, powered by **Twilio**, automatically:

* Logs into the user’s LinkedIn account
* Analyzes the user’s resume
* Finds relevant jobs
* Filters **Easy Apply** opportunities
* Sends curated job recommendations back on WhatsApp

👉 This eliminates repetitive job searching and makes applying faster and smarter.

---

## 🎯 Problem Statement

Job searching today is:

* Manual and time-consuming
* Repetitive across platforms

Users spend hours scrolling LinkedIn.

**CareerCo-Pilot solves this by automating the entire workflow using AI + automation.**

## 🧠 System Workflow

```text
User (WhatsApp)
      ↓
Twilio Webhook Trigger
      ↓
Backend Processing System
      ↓
Resume Analysis (AI/NLP)
      ↓
LinkedIn Login & Job Search
      ↓
Job Filtering (Relevance + Easy Apply)
      ↓
Results Sent Back via WhatsApp
```
